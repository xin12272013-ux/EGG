# 辩论与应答策略（接得住比讲得好更难）

> 触发场景：用户问"有人当众质疑我怎么办""演讲后的 Q&A 怎么接""即兴抽到辩论类题""汇报被领导追问""怎么反驳又不伤和气""对方说的明显不对但我不敢说"。
> 核心立场：**应答不是辩论赛，目标是"接住并加分"，不是"赢"。** 在头马和职场里，赢了一场争论、输了一个人，是净亏。
> 与 `table-topics-toolbox.md` 的分工：**那份讲"拿到题怎么开口"（输出型即兴），这份讲"被问到怎么接"（回应型即兴与对抗场景）。**
> 与 `evaluation-playbook.md` 的分工：那份讲"怎么给别人反馈"，这份讲"怎么接别人给你的挑战"。

---

## 1. 三大使用场景与各自的胜负标准

| 场景 | 特征 | 胜负标准 |
|------|------|----------|
| **演讲后的 Q&A** | 观众提问，你回应 | 答得清楚、不慌、不超时；让提问者觉得被尊重 |
| **头马即兴辩论 / 观点对立题** | 抽到"你同意 XX 吗"，需表态论证 | 立场清晰、有理由、有例子、有收尾 |
| **职场质疑 / 汇报追问** | 领导或同事当场挑战 | 不防御、给事实、给方案、不甩锅 |

**共同底线**：**不让人下不来台。** 包括你自己，也包括对方。

> EGG 例会里最常遇到的其实是第四种：**做完个评之后，被评者当场解释/辩解**。处理原则是——先接住他的情绪（"我理解你当时想表达的是……"），再回到你的建议本身，不改口也不硬顶。

## 2. 应答四步法（所有被问场景的通用动作）

```
① 听清 → ② 站位 → ③ 回应 → ④ 转回
```

| 步 | 做什么 | 关键动作 |
|----|--------|----------|
| **① 听清** | 确认对方真正问的是什么 | 没听清就问："你的意思是……对吗？"（这一问本身就在为你赢得思考时间） |
| **② 站位** | 决定你的态度：同意 / 部分同意 / 不同意 / 需要确认 | **永远不要自动防御**。先判断对方是不是敌人——大多数提问者是朋友 |
| **③ 回应** | 用第 4 节的框架组织回答 | 先给结论，再给理由 |
| **④ 转回** | 把话题接回你的主线 | "这个问题正好引出我接下来要说的……" |

> **新手最常见的错**：跳过了①直接到③，答了一个对方没问的问题。

## 3. 六类问题的应对模板

### 3.1 事实型（问数据、问细节）
- **知道** → 直接给数字 + 来源 + 一句解读
- **不确定** → **不要编**。"这个数字我记不准，会后我把准确数据发给你。"（诚实比编造安全 100 倍）
- **完全不知道** → "这个我没研究过，不敢乱说。你如果知道，我很想听。"

### 3.2 观点型（问你怎么看）
- 用 **PREP**：先给结论 → 一句理由 → 一个具体例子 → 重申结论
- 时间控制在 60-90 秒。超过 90 秒的 Q&A 回答会让人不耐烦

### 3.3 挑衅型（带情绪、带攻击性）
**三步拆弹**：
1. **不接情绪**：不回怼、不解释、不提高音量
2. **找合理内核**："你说的这点我认同——XX 确实是个问题。"（哪怕只认同 5%）
3. **给事实**："我这边的实际情况是……"

> **范例**：
> 问："你这个方案根本不接地气。"
> 答："你说得对，如果按这个版本直接推，一线确实会觉得麻烦。（认同内核）所以我留了过渡期，前两周走双轨，跑通了再切。（给事实）你那边最担心的具体是哪一步？（反问，把球传回去）"

### 3.4 陷阱型（二选一、预设前提）
- **识别**："你是支持 A 还是 B？"（明明有 C）/ "你为什么总是拖？"（预设你拖了）
- **破解**：**不接受预设**。"我不太同意这个二选一——其实还有第三种做法：……"
- 头马/职场都适用。接受一个错误的预设，后面怎么说都是输

### 3.5 超纲型（超出范围、涉及机密、涉及他人）
- **不越界**："这个涉及别人的隐私，我不方便在这里说。"
- **给替代**："不过我可以说说我自己的部分——"
- **转移**："这个问题更适合会后单独聊，我们现在先回到主线。"

### 3.6 沉默型（没人提问）
- 不要干等。自己抛：**"我知道大家这时候通常会问一个问题——XX。答案是……"**
- 或者指定："XX 你刚才一直在点头，你当时是怎么想的？"

## 4. 五种应答框架（按问题类型选）

| 框架 | 结构 | 适用 | 范例 |
|------|------|------|------|
| **PREP** | 观点 → 理由 → 例子 → 重申 | 观点型问题 | "我不同意。原因是……举个例子……所以我还是觉得……" |
| **STAR** | 情境 → 任务 → 行动 → 结果 | 追问经历/能力 | "那次项目延期的背景是……我的任务是……我做了……结果是……" |
| **桥接（Bridge）** | 认可 → 转折 → 我的信息 | 挑衅型、带偏的问题 | "这个问题很多人都关心（认可）。不过更关键的是（转折）……我们要解决的是（我的信息）" |
| **认可-补充（Yes, and）** | 同意 → 补充一层 → 深化 | 对方说得有道理，但你想加分 | "对，而且我想再补一层——" |
| **反问澄清** | 反问 → 澄清 → 再答 | 问题模糊、或需要争取时间 | "你问的是成本层面还是效果层面？如果是成本……" |

**框架选择一句话**：问观点用 PREP，问经历用 STAR，被怼用桥接，对方对就用 Yes-and，问题含糊就先反问。

## 5. 辩论结构（头马辩论赛 / 观点对立类即兴）

### 5.1 立论（60-90 秒）
```
立场（一句话，不含糊）
  ↓
标准（用什么标准判断，这是辩论的核心）
  ↓
理由 1 + 证据
  ↓
理由 2 + 证据
  ↓
重申立场
```
> **立论的关键是"定标准"**。把判断标准定在对自己有利的维度上，你就赢了一半。
> 例：辩"线上学习好不好"——把标准定成"学习效果"你就赢；定成"社交体验"你就输。先说标准。

### 5.2 驳论（30-60 秒）
```
对方说了什么（准确复述，不歪曲）
  ↓
错在哪 / 哪一步跳了
  ↓
正确的说法是什么
  ↓
回到我的立场
```
> **绝不歪曲对方观点**（稻草人谬误）。歪曲一次，全场都知道你理亏。

### 5.3 质询（一问一答）
- 每个问题**只问一件事**，且是**封闭式问题**（能答是/否）
- 问题要**连环**：前一句的答案，是后一句的前提
- 目的不是得到答案，是让对方自相矛盾
- **被质询时**：守住核心，不追着对方的节奏走。答完立刻转回自己的点

### 5.4 结辩（60 秒）
- 不复述过程，只做**价值升华**
- 回到"为什么这个立场重要"
- 最后一句是金句，说完就停，不再解释

## 6. 逻辑谬误速查（识别对方的，也别让自己犯）

| 谬误 | 长什么样 | 怎么破 |
|------|----------|--------|
| **稻草人** | 歪曲你的观点再攻击 | "这不是我的意思，我说的是……" |
| **人身攻击** | 不反驳观点，攻击人 | "我们回到观点本身——" |
| **滑坡** | "一旦 A，就会 B，然后 C，最后完蛋" | "从 A 到 C 中间有几步，我们一步一步说" |
| **非黑即白** | 只给两个选项 | "还有第三种可能——" |
| **诉诸情感** | 用煽情代替论证 | "我理解这个感受。我们看数据——" |
| **以偏概全** | 一个例子推出普遍结论 | "这是个例，样本足够吗？" |
| **诉诸权威** | "XX 说的就是对的" | "XX 在这个领域确实是权威，不过在这个具体问题上——" |
| **循环论证** | 结论藏在前提里 | "你等于把要证明的话又说了一遍" |
| **相关即因果** | 先后发生就当因果 | "这两件事同时发生，不代表一个是另一个的原因" |
| **诉诸群众** | "大家都这么认为" | "多数人认同不等于正确，我们看证据" |

## 7. 12 句救场话术（背下来，被问住时直接用）

**争取时间**
1. "这个问题很好，让我想三秒钟。"
2. "你问的是 A 层面还是 B 层面？"（反问本身就是思考时间）
3. "在回答之前，我想先确认一下你的意思是……对吗？"

**不知道 / 不确定**
4. "这个我不敢乱说，会后我把准确信息给你。"
5. "这个问题我没想过，但我的第一反应是……"（诚实 + 给思考）
6. "说实话，答案我不知道。但我知道的是……"

**被怼 / 挑衅**
7. "你说的这点我认同——"（先认同，永不亏）
8. "你提的这个问题比我的答案更重要，因为它指出了……"
9. "我们可能不冲突。你说的是 A，我说的是 B，这两件事可以同时成立。"

**跑题 / 太长**
10. "我怕说太长，先给结论：……需要的话会后细聊。"
11. "这个话题值得单独聊一场，我现在先回到主线——"

**收尾转回**
12. "这个问题正好引出我接下来要说的——"

> **头马个评场景专用**（用户做完个评被追问/被解释时）：
> - "我理解你当时想表达的是 XX，效果确实到了。我说的那一点，是给你下一次多一个选项。"
> - "我给的只是一条建议，你可以试试，不合适就丢掉——评估不是标准答案。"

## 8. 风度与边界（不吵架的三原则）

1. **对事不对人**：永远攻击观点，不攻击人。说"这个方案有个风险"，不说"你不专业"
2. **承认比狡辩强**：错了就说"你说得对，我记错了"。承认一个小错，可信度反而上升
3. **知道什么时候停**：对方明显不是在寻求答案（只是要发泄/要表态），就给台阶、转话题。**赢不了的争论，不接**

**三条红线**（头马与职场通用）：
- 不人身攻击、不揭短
- 不用情绪压人（不提高音量、不讽刺）
- 不当众让领导下不来台（有意见私下提，公开场合给选择而非给难堪）

## 9. 练习法（应答是可以练出来的）

| 练法 | 怎么做 | 练什么 |
|------|--------|--------|
| **随机提问法** | 让朋友在你讲完后随机提 3 个问题，必须用 PREP 在 90 秒内答完 | 快速组织 |
| **反方练习** | 为自己的观点找 3 个最强的反对理由，提前准备好回应 | 预判抗拒 |
| **录影复盘** | 录下 Q&A 环节，看自己的第一反应：有没有防御性动作（抱臂、后退、皱眉） | 身体语言 |
| **慢答训练** | 被问后强制沉默 2 秒再开口 | 消除慌张感 |
| **头马即兴辩论** | 抽到观点题时刻意选自己不认同的立场讲 | 思维的弹性 |

**每日一练（5 分钟）**：随便挑一个热点话题，用 60 秒讲支持方，再用 60 秒讲反对方。坚持两周，临场反应会有明显变化。

**EGG 例会里的练法**：备稿演讲结束后，**主动请一位会员提一个尖锐问题**，当着全场答一遍。这是唯一一个"有人给你出题、还有人给你计时"的免费训练场。

## 附：给蛋导的用法

用户说"我怕被提问"，不要只安慰，按第 3 节帮他**把可能被问的 5 个问题列出来并预演一遍**——90% 的恐惧来自未知。

用户描述被怼的经历时，先用第 6 节判断对方用了什么谬误，再用第 7 节给具体话术，而不是笼统地说"你要自信"。

用户要参加辩论赛/抽到观点对立题时，按第 5 节给完整的立论-驳论-质询-结辩四段结构，并要求他**先把"标准"那一句写出来**——这一句决定了整场辩论的走向。
