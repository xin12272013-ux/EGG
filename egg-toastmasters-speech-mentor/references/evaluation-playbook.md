# 评估技巧全手册（五种评估角色 + 话术库）

> 触发场景：用户说"下周轮到我做个评""怎么做总评""即兴怎么评""我该怎么给自己评""怎么给别人反馈才不伤人""评估结果怎么写"，或担任会议任何评估角色时。
> 核心立场：**评估不是挑毛病，是给一条下一步能走的路。** 好的评估让被评者当场就想改，坏的评估让人只想辩解。
> 与 `case-study-and-peer-eval.md` 的分工：
> - **那一份** = 改稿案例（《差一点》迭代）+ 三明治法基础 + **真实评估案例库**（《旧木箱》78 分、《带着恐惧上台》80 分的实战复盘）
> - **这一份** = "怎么评"的完整操作手册：五种角色、观察清单、时间分配、分层侧重、话术库、可照念的范例
>
> 两份配套使用：用户要做个评时，**先读这一份搭结构，再读那一份看真实案例的定级与破局点怎么落笔**。

---

## 0. 五种评估角色与各自的评什么

| 角色 | 评的对象 | 时长 | 核心任务 |
|------|----------|------|----------|
| **个评**（Individual Evaluator） | 一篇备稿演讲 | 2-3 分钟 | 让演讲者知道做得好的和下一步该练的 |
| **总评**（General Evaluator） | 整场会议 | 3-5 分钟 | 评所有没被评到的人与流程 |
| **即兴评估**（TT Evaluator） | 一轮即兴演讲 | 1-2 分钟/人 或 5 分钟/轮 | 点评每人是否答完题、结构是否立住 |
| **比赛评委**（Judge） | 参赛演讲 | 打分 + 书面意见 | 按内容50/表达30/语言20 定级排序 |
| **自评**（Self-Eval） | 自己的录像 | 15 分钟 | 找出 3 个改稿点 |

## 1. 个评（最核心的角色）

### 1.1 个评的三条铁律

1. **评的是演讲，不是人**。说"这个开场的节奏可以再压一下"，不说"你太紧张了"
2. **每条建议都要能执行**。"下次可以试试……" 而不是 "你要更有感染力"
3. **优点要具体到原话**。泛泛的"讲得很好"等于没说；引用他讲的那句话，他才知道好在哪

### 1.2 三种评估结构（按场景选）

| 结构 | 组成 | 适用 |
|------|------|------|
| **三明治法** | 优点 2-3 → 建议 1-2 → 鼓励期待 | 通用，新手个评首选 |
| **4-1-1** | 4 个优点 + 1 个建议 + 1 个期待 | 俱乐部常用，保证正反馈比例 |
| **CRC**（Commend-Recommend-Commend） | 表扬 → 建议 → 表扬 | 头马官方体系，英文俱乐部常用 |

**比例原则**：优点与建议约 **2:1**。建议超过两条，被评者一条都记不住。

### 1.3 观察清单（听的时候记这些，不要空手评）

**内容（50%）**
- [ ] 核心信息是什么？一句话能说清吗？
- [ ] 开头 30 秒有没有抓住我？
- [ ] 结构清不清楚？我能不能复述出他的框架？
- [ ] 有没有转折/情绪起伏？（判据：≥2 次，见 `material-and-tension.md` §2）
- [ ] 有没有一个让我记住的瞬间或一句话？
- [ ] 结尾有没有收住？有没有回扣开头？
- [ ] **标题和内容咬得住吗？**（《旧木箱》那一稿就栽在这里）

**表达（30%）**
- [ ] 眼神有没有看人？覆盖了几个区域？
- [ ] 手势是否自然、是否与内容同步？（手势比语言早 0.5 秒）
- [ ] 站姿/走位是否有设计？有没有无意识晃动？
- [ ] 声音有没有快慢、轻重、停顿的变化？（≥3 处停顿、≥1 处音量骤降）
- [ ] 是否真诚投入，还是在背稿？

**语言（20%）**
- [ ] 用词是否口语化？有没有书面腔/AI味？（破折号、冒号引号是重灾区）
- [ ] 有没有口头禅（然后/就是/那个/嗯）？数出来
- [ ] 有没有特别精彩的用词或修辞？
- [ ] 语法与发音有无明显问题？

**项目目标（Pathways）**
- [ ] 这次演讲的项目目标是什么？（破冰/组织/视觉辅助/说服……）
- [ ] 达成了吗？证据是什么？

> **记笔记的方法**：准备一张纸分三栏（内容/表达/语言），听到什么记什么，标注时间点（"2:15 那个停顿很好"）。评的时候直接引用时间点，专业感立刻出来。

### 1.4 优点的写法（三步）

```
① 引用具体的一句原话或一个动作
② 说明它产生了什么效果
③ 点出背后的技术名称（让他以后能复现）
```

**范例**：
> ❌ "你的开场很好。"
> ✅ "你开场第一句是'我被人当场辞退的那天，是腊月二十八'——我当时立刻坐直了。这就是直接抛冲突，比任何自我介绍都有效。以后所有叙事型演讲，你都可以这么开。"

### 1.5 建议的写法（三步）

```
① 描述现状（客观，不带评价）
② 给出具体的替代做法（"下次可以试试……"）
③ 说明这么改会有什么效果
```

**范例**：
> ❌ "你讲得太快了，要慢一点。"
> ✅ "中间讲考证那一段，你用了大概 40 秒讲了三年。下次可以试试：把三年压缩成一句话带过，把剩下的时间给'查分那天早上'这一个场景——放慢到讲清楚你手抖到点不开网页。观众记住的是那一个瞬间，不是那三年。"

**建议的三个禁区**：
1. 不提"你应该"（改成"可以试试"）
2. 一次不超过 2 条
3. 不给互相矛盾的建议（"你要多用手势"和"你要站定别晃"）

### 1.6 时间分配（2.5 分钟个评模板）

| 段 | 时长 | 内容 |
|----|------|------|
| 开场 | 15 秒 | 点出演讲标题 + 项目目标 + 一句总体感受 |
| 优点 | 60 秒 | 2-3 个，每个都要引用原话 |
| 建议 | 60 秒 | 1-2 个，每个给具体替代做法 |
| 收尾 | 15 秒 | 一句鼓励 + 一句对下次的期待 |

### 1.7 分层评估侧重（同一篇稿，对不同人给不同建议）

| 被评者层级 | 主要给什么 | 不要给什么 |
|-----------|-----------|-----------|
| **新手（前 3 篇）** | 结构、眼神、完成度。大力肯定 + 只给 1 条建议 | 不要评手势细节、不要评幽默，会把他搞崩 |
| **进阶（4-10 篇）** | 转折设计、高光时刻、口头禅、节奏 | 不要只夸不提问题，他需要往上走 |
| **比赛级** | 张力、非共识价值点、回环结构、每一个停顿 | 不要给泛泛建议，要精确到秒和字 |

### 1.8 完整个评范例（可直接模仿）

> **开场**："XX 的《带着恐惧上台》，是 Pathways L2 的项目，目标是'有效的肢体语言'。我听完最大的感受是——你把自己真正害怕的东西讲出来了，这需要勇气。"
>
> **优点一**："开场那句'我把车停在楼下，熄火，坐了二十分钟没上去'——我立刻就知道这篇要讲什么了。用一个具体的动作开场，比说'我今天很紧张'强十倍。"
>
> **优点二**："你在讲考证那段的时候，声音压低了，语速也慢下来。这个变化非常明显，全场都静了。这说明你的声音是有设计的，不是平铺直叙。"
>
> **优点三**："结尾回扣了开场的'坐在车里'——'现在我下车了'。首尾呼应，这一下把整篇收紧了。"
>
> **建议**："有一个地方我觉得可惜。师父那句'你不是不会说话，你是怕说完没人接'，这是全篇最有力量的一句，但你紧接着就讲下一段了。下次可以试试：说完那句，停三秒，什么都不说，让全场消化完再往下走。这一句值得一个三秒的停顿。"
>
> **收尾**："总的来说，这是我在这个俱乐部听到的最有真实感的一篇。我期待你的下一篇——希望那时候你已经不需要坐二十分钟了。"

## 2. 总评（General Evaluator）

### 2.1 总评评什么

**总评不评备稿演讲**（那是个评的活），评的是**整场会议的运行质量**：

- 会议是否准时开始/结束
- 主持人串场是否流畅
- 各官员角色履职情况（计时员、语法员、哼哈官、总主持人）
- 即兴主持的题目质量
- 个评们的评估质量
- 会场布置、氛围、来宾接待

### 2.2 总评结构（3-5 分钟）

| 段 | 内容 |
|----|------|
| 1. 总体印象 | 一句话定调（"这是一场高效的会议" / "这是一场温暖但偏慢的会议"） |
| 2. 逐个角色点评 | 每个角色 1 个优点 + 最多 1 个建议，**按出场顺序** |
| 3. 亮点时刻 | 挑 1-2 个全场最好的瞬间具体说 |
| 4. 改进建议 | 1-2 个，针对**流程**而非个人 |
| 5. 收尾 | 肯定 + 期待 |

### 2.3 总评观察清单

- [ ] 会议是否准时开始？超时多久？
- [ ] 各环节衔接有无空档、冷场？
- [ ] 计时员是否举牌及时、是否解释了规则？
- [ ] 语法员是否给了"今日一词"并有使用统计？
- [ ] 哼哈官是否统计并报告了口头禅？
- [ ] 即兴环节题目是否清晰、是否有足够人参与？
- [ ] 个评们是否都守时、结构是否完整？
- [ ] 有没有来宾被冷落？
- [ ] 掌声、笑声、互动氛围如何？

### 2.4 总评范例（片段）

> "这是一场准时开始、准时结束的会议——这在俱乐部里不常见，值得肯定。
>
> 计时员 XX 在开场就解释了绿黄红牌规则，这一点很多新会员不知道，做得好。一个建议：下次可以在举牌时稍微站到演讲者视线范围内，今晚第二位演讲者好像没看到黄牌。
>
> 语法员的'今日一词'是'裂痕'，全场用了 7 次，统计很清楚。
>
> 即兴环节的题目都很好，尤其是'你最不想承认的一个缺点'——这个题目让三个人都讲了真心话。唯一可惜的是时间紧，最后一位只有 40 秒。
>
> 全场最亮的瞬间：XX 做个评时引用了演讲者的原话并标了时间点。这是专业评估的样子，建议大家学。
>
> 一个改进建议：会议比预定晚了 8 分钟结束，主要卡在环节衔接。下次总主持可以在每个环节结束前 10 秒给个手势提示。"

## 3. 即兴演讲评估（Table Topics Evaluation）

### 3.1 与备稿评估的最大区别

**即兴是"先有题后有稿"，第一评分项是"有没有答完题"。**
备稿评估的七维表（开场/结构/转折/幽默/口语化/结尾/舞台提示）**对即兴不完全适用**。

### 3.2 即兴七维（每项 1-5 分）

| 维度 | 评什么 |
|------|--------|
| **前 10 秒切入** | 第一句是否把听众"扔进现场"（时间 + 身份 + 处境），还是开场即迷路 |
| **题目响应度** | ⭐ 逐问拆解题目，判定 达标 / 未答 / 未触及 |
| **结构清晰度** | PREP / STAR 骨架是否立住，Point 有没有回扣 |
| **故事具象度** | 有无直接引语、可感动作、具体数字 |
| **转折与洞察** | 情节转折之外，有没有**认知转折**（"我突然意识到"这一拍） |
| **幽默感** | 不强求，但一个自嘲能立刻拉近距离 |
| **语言口语化** | 自然不端着，扣口头禅 |

**中文即兴专项三维**（蛋导出 PDF 报告时必列）：

| 维度 | 评什么 |
|------|--------|
| 口头禅/填充词 | "然后/就是"密度；即兴压力下会翻倍，需用停顿强行顶替 |
| 时间控制 | 绿区 1'00"–1'30"，2'00" 红线。**偏短 = 洞察层没展开** |
| 题目响应度 | 逐问拆解，判定 达标/未答/未触及 |

### 3.3 即兴诊断的第一动作

**把题目拆成两问，逐条判定。**

> 例：题目是"讲一次被误解的经历，你从中学到了什么？"
> - 问一：讲了被误解的经历吗？→ 讲了吗？讲清楚了吗？
> - 问二：讲了学到了什么吗？→ **最常见的失分点：讲了经历，忘了讲学到什么。**

**即兴演讲最常见的失分不是讲得不好，是答错一半题。**

> **高价值信号**：如果演讲者自己说出了一句**天然就是答案的话**（如"他不知道我在做什么"），却说完就滑过去没停——那这就是本场最值钱的改稿点，把它提为峰值。

### 3.4 即兴评估范例

> "题目是'你最不想承认的一个缺点'。
>
> 你的第一句'我有拖延症，而且我不打算改'——全场笑了，这个开场很好，直接把听众抓住了。
>
> 结构上你用了 PREP：先给结论，讲了上周赶稿的例子，最后收回到'我承认它，但我跟它和平共处'。骨架是完整的，Point 回扣了。
>
> 题目响应度：题目问的是'最不想承认的缺点'——你讲了缺点，也讲了不想承认，两问都答到了。
>
> 一个建议：中间那个赶稿的例子，你说'熬了一整夜'，如果加一个具体数字会更好——'凌晨四点十七分，我按下了发送'。即兴演讲的说服力全在细节上，一个数字顶三句形容词。
>
> 另外，'然后'出现了 11 次。下次可以试试：想说'然后'的时候，闭嘴一秒。"

## 4. 比赛评委评分（模式 B）

评分标准与定级见 SKILL.md 主体（内容 50 / 表达 30 / 语言 20 + 得分定级表）。这里补充评委视角的三条经验：

1. **先打分，再看人**。同一场里，先给每篇打出原始分，最后统一排序，避免被前一篇的印象带偏
2. **内容 50% 是硬底线**。表达再好，内容站不住，不能进前三
3. **写评语时给"可改的具体动作"**。参赛者最需要的是"第三段的停顿再长半秒"，不是"表达可以更生动"

**蛋导出评估报告时的三条规矩**：
1. 先给分区间 → 再定级别 → 一句话说明为什么定在这（不给孤零零一个数字）
2. 破局点只给 1-2 个，**标上"+X 分"的预估收益**
3. 结尾的"评委口吻一句话"必须犀利，但要指出路——只损不给路的评语是耍帅，不是评估

## 5. 自评（最容易被跳过、也最有效的角色）

### 5.1 录像回看三遍法

| 遍 | 怎么看 | 记什么 |
|----|--------|--------|
| **第 1 遍：只听声音**（不看画面） | 闭眼或转过身 | 语速、口头禅、停顿位置 |
| **第 2 遍：只看画面**（静音） | 静音播放 | 站姿、手势、眼神、面部 |
| **第 3 遍：正常看** | 完整看 | 整体节奏、观众反应、时间控制 |

每遍各记 3 个问题，共 9 个 → **挑最致命的 3 个，下次只改这 3 个**。

### 5.2 自评九问

1. 我的核心信息，观众能一句话复述出来吗？
2. 开场 30 秒抓住人了吗？
3. 我的眼神覆盖了几个区域？
4. 我有几个明确的手势？
5. 全篇有几处超过 1 秒的停顿？
6. 口头禅出现了几次？
7. 时间误差多少秒？
8. 观众在哪里笑了/安静了？那是我设计的吗？
9. 如果只能改一处，改哪里？

### 5.3 自评表（可直接复制使用）

| 项目 | 目标 | 实测 | 差距 | 下次改什么 |
|------|------|------|------|-----------|
| 时长 | 5:00-7:00 | | | |
| 口头禅次数 | ≤3 | | | |
| 停顿次数 | ≥3 | | | |
| 手势次数 | ≥5 | | | |
| 眼神覆盖区 | 5 区 | | | |
| 笑点/反应点 | ≥2 | | | |

## 6. 其他角色速评（1 分钟内，给总评时被顺带评到）

| 角色 | 职责要点 | 常见扣分点 |
|------|----------|-----------|
| **计时员** | 解释规则、准时举牌、记录时间 | 没解释规则；举牌位置演讲者看不到 |
| **语法员** | 今日一词、好词好句收集、错误提醒 | 今日一词没人用；只报错不报好 |
| **哼哈官** | 统计口头禅、会后报告 | 只报总数不报具体词；语气像批评 |
| **主持人** | 串场、介绍、控时 | 念稿、拖沓、介绍太长 |
| **即兴主持** | 出题、控时、点人 | 题目含糊；冷场时点名太慢 |

## 7. 话术库（可直接用的表达）

### 7.1 开场定调

- "这篇演讲的 XX 项目目标是……我听完最大的感受是……"
- "我在听的时候记了三页笔记，这说明你全程都抓住了我。"
- "先说一句：你把自己真正害怕的东西讲出来了，这需要勇气。"

### 7.2 夸优点

- "你那句'……'——我当时立刻坐直了。"
- "这里你有一个很明显的设计：声音压低了，全场都静了。"
- "这是我在这个俱乐部听到的最有真实感的一篇。"
- "你的手势和语言是同步的，不是加出来的。"
- "首尾呼应，这一下把整篇收紧了。"

### 7.3 给建议（软着陆）

- "有一个地方我觉得可惜……"
- "下次可以试试……"
- "如果这里再……，效果会更好。"
- "我给你一个具体的动作：……"
- "这一句值得一个三秒的停顿。"
- "我的建议只有一条，因为我只想让你记住一条。"

### 7.4 收尾鼓励

- "总的来说，完成度很高。我期待你的下一篇。"
- "你比你自己以为的好。"
- "我期待下次看到你把 XX 改掉之后的样子。"
- "保持这个真实感，别丢掉它。"

### 7.5 应对"我不知道该评什么"

- 挑**一个**你真正被打动的瞬间，说清楚它为什么打动你——这本身就是最好的评估
- 挑**一个**你觉得最可惜的地方，给一个具体替代做法
- 剩下的不用硬凑

---

## 8. 评估的禁忌与红线

| 禁忌 | 为什么 | 替代做法 |
|------|--------|----------|
| 泛泛而谈（"很好""不错"） | 被评者学不到任何东西 | 引用原话，说明效果 |
| 一次给 5 条建议 | 一条都记不住 | 最多 2 条 |
| 评价人格（"你太紧张了"） | 伤人，且不可改 | 描述行为（"这一段的语速比前面快了"） |
| 复述演讲内容 | 浪费时间，我们知道他讲了什么 | 直接说好在哪、差在哪 |
| 建议互相矛盾 | 被评者无所适从 | 只给一个方向的建议 |
| 把自己的风格强加给对方 | 剥夺他的声音 | "这个可以试试，不一定适合你" |
| 只夸不提建议（对进阶会员） | 阻碍成长 | 进阶会员必须给 1 条硬建议 |
| 超时 | 占用别人的时间 | 严格 2-3 分钟，提前排练 |

---

## 9. 给被评估者：怎么接收评估

1. **不辩解**。听到不同意见，先说"谢谢，我会试试"。辩解会让以后没人敢给你真话
2. **记三条**。当场记下最刺耳的三句——最刺耳的往往最有用
3. **只改一条**。下次演讲只改一条，改透了再换下一条
4. **感谢评估者**。他是全场唯一一个全程盯着你、为你好的人

## 附：给蛋导的用法

用户说"我要做个评"时，**先问三件事**：被评者是谁、他的层级（新手/进阶/比赛级）、这次的 Pathways 项目目标。然后按 1.7 的分层侧重 + 1.6 的时间分配，生成一份**可直接照着念的逐字评估稿**（含开场、2-3 个优点、1-2 个建议、收尾），而不是只给方法论。

用户说"我下周做总评"时，按第 2 节给结构 + 观察清单，并提醒他**会议中要实时记笔记，不要靠回忆**。

用户要评即兴时，必须先拿到**题目原文**——没有题目就无法做题目响应度判定，而这是即兴评估的第一项。

评估/改稿结论默认出 PDF（走 SKILL.md「五、交付规范」），即兴评估用靛蓝色系 `#1d4ed8` 区分。
