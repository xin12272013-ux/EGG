# 六维深度磨稿工具箱（模式D完整版）

> 本文件是 SKILL.md「模式D：六维深度磨稿」的完整工具箱。进入深度磨稿时读取本文件，按需取用各工具。

## 六维模型

| 维度 | 权重 | 核心问题 |
|------|------|----------|
| 内容/开发 | 50% | 结构是否有效？核心信息是否清晰？故事是否有价值？ |
| 交付效果 | 30% | 肢体、声音、舞台移动是否有设计？ |
| 语言 | 20% | 用词是否口语化？是否还有AI味/书面腔？ |
| 幽默 | 贯穿 | 笑点分布是否均匀？是否自然不刻意？ |
| 转折 | 贯穿 | 是否有心理斗争和情感波动？ |
| 舞台提示 | 贯穿 | 停顿、走位、肢体是否有明确标注？ |

## 工具1：结构优化

**三段式黄金结构**（最常用且有效）：

```
开场Hook（30秒内抓住注意力）
  ↓
第一段：起点/问题/现状
  ↓ 过渡句
第二段：转折/挣扎/冲突
  ↓ 过渡句
第三段：突破/成长/收获
  ↓
结尾Takeaway（核心金句 + 行动号召）
```

结构检查要点：
1. 每段有明确的要点，不跑题
2. 段落之间自然过渡，不用"接下来""然后"等机械连接词
3. 情感曲线：起→伏→起，不能一条直线
4. 开场和结尾呼应（首尾对照效果最强）

常见结构问题及修复：
- 开场铺垫太长 → 砍掉前30秒废话，直接切入冲突
- 三段平均用力 → 重点放在转折段，压缩铺垫段
- 结尾太散 → 提炼一句话核心金句，用排比收束

## 工具2：语言打磨——去AI味与口语化

**AI味检测清单**（逐项排查）：

| AI味特征 | 表现 | 修复方法 |
|----------|------|----------|
| 小标题滥用 | "第一点""首先""其次" | 删掉小标题，用过渡句自然衔接 |
| 破折号堆砌 | "——"频繁出现 | 改为句号断句，或逗号连接 |
| 冒号引导 | "我心想：""他说：" | 改为逗号或直接引述 |
| 过度对仗 | "不是A，而是B"大量出现 | 打破对仗，用口语化表达替代 |
| 空洞修饰 | "深深地""缓缓地""坚定地" | 删掉副词，用动作描写替代 |
| 书面腔 | "因此""然而""综上所述" | 换成"所以""但是""说白了" |
| 完美主义 | 每句都工整对仗 | 故意制造长短句交错，加入碎句 |
| 公式结尾 | "让我们一起..." | 用具体的、个人化的结尾替代 |

**口语化技巧**：
- 短句优先：一句话不超过20个字，长了就断
- 用"你""我"拉近距离：不用"大家""我们每个人"
- 加入语气词：少量"嘛""啊""呗"增加真实感
- 自嘲是最好的亲和力：敢拿自己开涮
- 对话感：想象在跟一个朋友聊天，不是在"发表演讲"

## 工具3：幽默设计

| 类型 | 示例 | 适用位置 |
|------|------|----------|
| 自嘲 | "写了20年代码，最擅长的事就是不说话" | 开场破冰 |
| 反差 | "六个小时写了47个字，连大家好和谢谢都算上" | 叙事中段 |
| 续句补刀 | "催债的为了钱，我催你备稿——是为了你" | 情感段后 |
| 模仿 | 模仿师父语气、老板表情 | 故事讲述 |
| 误导反转 | 铺垫严肃方向，突然给个意外结局 | 任何位置 |
| **三段式反转** | 前两句顺着常规逻辑铺垫，**第三句意外反转** | 任何位置（最易上手的一型） |
| **CallBack 梗复用** | 开场埋一个梗，中后段回收再抖一次 | 首尾各一次，笑点本身也成闭环 |

> 后两型与闭环手法详见 `champion-blueprint.md` §5、§6（含比赛密度标准：每 30–60 秒一个，不碰情感高潮）。

幽默设计原则：
1. 笑点分布均匀，每隔30-60秒一个，不要扎堆
2. 不碰情感高潮——到了走心的地方就收住幽默
3. 幽默服务于主题，不为搞笑而搞笑
4. 续句补刀模式最有效：正句说完，停顿，补一刀
5. 自嘲永远安全，调侃别人要小心
6. 标注【等笑声】给自己和观众留时间

## 工具4：转折与情感设计（高光时刻在这里诞生）

**转折设计模板**：

```
状态A（舒适/惯性）
  ↓ 触发事件
心理斗争（想要退缩/犹豫）
  ↓ 关键决定
状态B（突破/成长）
```

**情感波动检查**：
- 有"差点放弃"的时刻吗？（观众最爱听挣扎）
- 有"顿悟"的瞬间吗？（观众需要跟着你一起明白）
- 有"前后对照"吗？（加入前vs加入后，犹豫vs行动）
- 情感不能一条线到底——要有笑有泪有思考

**心理斗争写法**：
- 具体化内心独白：不说"我很犹豫"，要说"手放在门把手上，推，还是不推？"
- 用身体反应代替形容词：不说"我很紧张"，要说"腿抖得像缝纫机"
- 用时间细节增加真实感："从晚上八点坐到凌晨两点""三十秒里我想了三件事"

**高光时刻（The Moment）设计**——冠军演讲与好演讲的分水岭：
- 一篇比赛稿至少设计**一个**高光时刻，放在全程70%-80%处（情绪顶点）
- 高光的形态：一句压完全场的金句 / 一个定格的画面 / 一次前后对照的揭示
- 高光前必须留白：【停顿3秒】再抛出，让全场安静下来接住它
- 高光后不加解释，用短句收住，让观众自己回味

## 工具5：舞台提示标注体系

| 标注 | 含义 | 使用时机 |
|------|------|----------|
| 【停顿】 | 1-2秒停顿 | 重要观点后、转折前 |
| 【停顿3秒】 | 加重停顿 | 核心金句前、高光时刻前 |
| 【等笑声】 | 等待观众笑声 | 抛出笑点后 |
| 【环顾全场】 | 眼神扫过观众 | 开场、结尾 |
| 【微笑】 | 面部表情 | 温暖段落 |
| 【自嘲地笑】 | 带自嘲的表情 | 自嘲笑点后 |
| 【加重语气】 | 声音加重 | 关键观点 |
| 【放慢语速】 | 减慢节奏 | 走心段落 |
| 【模仿XX】 | 模仿动作/语气 | 讲述他人时 |
| 【指向台下】 | 手势指向观众 | 互动段落 |
| 【身体后仰】 | 肢体后退 | 表现犹豫 |
| 【鞠躬】 | 鞠躬致谢 | 结尾 |

舞台提示原则：
- 每个自然段至少一个舞台提示
- 停顿比动作多——留白是力量
- 肢体语言要自然，不为动而动
- 标注要具体——"停顿"不够，要写"停顿，等笑声落下"

## 工具6：计时规划

**计时分配模板**（以7分30秒为例）：

| 段落 | 内容 | 目标时长 | 累计 |
|------|------|---------|------|
| 开场 | Hook + 主题引入 | 0:45 | 0:45 |
| 第一段 | 起点/问题 | 1:30 | 2:15 |
| 第二段 | 转折/挣扎 | 2:00 | 4:15 |
| 第三段 | 突破/成长（含高光时刻） | 1:45 | 6:00 |
| 结尾 | 金句 + 行动号召 | 1:30 | 7:30 |

计时调整原则：
- 笑点密集区多留10-15秒给笑声停顿
- 走心段落语速放慢，字数适当减少
- 超时优先压缩铺垫段
- 不足时在转折段多加停顿和细节
- 比赛演讲严格控制在绿黄红信号区间内
