## 1. 人生曲线法（治"我没故事可讲了"）

**症状**：讲完自己、父母、孩子的故事后，觉得素材枯竭。

**方法**：给自己画一条曲线——横轴**人生阶段（时间轴）**，纵轴**心情评分（-10 ~ 100）**。

现场演示的完整曲线（可作示范模板）：

```
小学 70 → 小升初失利 20 → 市重点 80 → 保送失败 30 → 华师大 85 → 系里最高薪 90
→ 原地踏步 40 → 跳槽连升三级 80 → 职业瓶颈 80→95→回落 → 大厂巅峰 100
→ 回沪三月无业 -10 → 再失业 30 → 财务自由 80 → 人事斗争 40 → 创业 90
```

**三个要点**：
1. 每个人的人生都是这条波形曲线，素材**讲不完**，只是波形不同
2. 最好的素材都在**波谷和波峰**上，而最最好的，是**"从低谷怎么爬起来"**的那一段
3. 一条好演讲必须带着情绪走——**没有情绪，故事再好也只是"分享"，不是演讲**。心情评分轴就是情绪的可视化工具

**落地动作**（模式A 素材不足时的第一指令）：
> 花 20 分钟画你自己的心情曲线：列时间轴 + 每个阶段打心情分，标出 **3 个最深波谷、3 个最高波峰**，每个点写一句平实的事件描述。这就是素材库的种子。

**两条挖矿路径（枯竭时先换路径，再换素材）**：

| 路径 | 挖什么 | 出处 |
|---|---|---|
| **人生曲线**（时间轴） | 从**过去**挖：波峰波谷事件 | 本文 §1 |
| **乔哈里窗**（认知轴） | 从**当下**挖：隐藏区（不敢讲的事）+ 盲区（别人眼里的你） | `inspiration-workshop.md` §1 |

**素材库运维**：人生曲线是**一次性深挖**（建种子库），日常靠"灵感捕手"**持续供给**（每日 3 个 + 每周整理 15 分钟），见 `inspiration-workshop.md` §2。

## 2. 张力：好故事的发动机

现场互动式定义（可直接复用为教学话术）："张力是什么？"

| 张力来源 | 说明 |
|---|---|
| **弹簧** | 越压反弹越强——压力与反弹的势能差 |
| **对比** | 强弱、快慢、高低之间的落差 |
| **反转** | 预期之外的方向改变 |
| **冲突** | 正面碰撞，戏剧核心 |
| **一波三折** | 多次下滑与上升的连续起伏 |

**本质定义**：张力 = 让听众产生**情绪起伏**，从而获得启发或昂扬向上的动力。

**落地判据（张力自检）**：
> 写完故事自查——听众的情绪曲线有没有**至少 2 次以上明显的下压与反弹**？一路平推的叙述没有张力。

模式B 评估、模式D 磨稿时直接套这条判据。

**冲突分两层，内层优先**（比赛级要求，详见 `champion-blueprint.md` §4.2）：

| 层 | 内容 | 权重 |
|---|---|---|
| **外部冲突** | 环境、他人、困境、现实压力 | 只是舞台 |
| **内部冲突** | 自我怀疑、纠结、恐惧、不甘、两难选择 | **内心冲突 > 外部冲突**，挣扎越深共情越强 |

> 自检：把故事里的外部困难全部拿掉，**剩下的内心两难还成立吗**？不成立 = 你写的是一个事件，不是一个故事。

## 3. 素材加工三步曲

1. **平实记录**：先用平时的语言把事件本身写下来，不做修饰
2. **价值提炼**：从事件里挖价值点（方法见 §5、§6）
3. **结构加工**：套骨架重组（方法见 §9、`speech-writing-methodology.md` §四）

**顺序不能倒。** 先想结构再挖内容，容易写成空壳；先记录再提炼，内容才立得住。

> 三步曲是总纲，`speech-writing-methodology.md` §五的四步写作法（审题选材→思辨立意→结构脉络→语言文采）是第三步"结构加工"的展开。

## 4. 素材五大类（素材积累的完整清单）

| 类别 | 子类 | 作用 |
|---|---|---|
| **故事类** | 本人故事 / 周围人故事 / 名人故事（马云、马斯克）/ 热点故事 / 虚构故事（孙悟空、复仇者联盟） | 张力的主要载体；虚构与热点故事本身自带张力，可直接引用 |
| **数据类** | 学术研究 / 统计数据 / 调查数据 | 说服力。例："90% 以上的人有拖延行为""立 flag 的人中只有 6% 完成目标"——同时给听众"我并不特殊"的宽慰感 |
| **观点类** | 金句格言 | 记忆锚点。例："能力就是能做某类事儿，不费力——'能'和'力'都放进去了" |
| **互动类** | 幽默段子 / 现场互动 | 调节节奏、连接现场（例：现场有脱口秀俱乐部嘉宾时点名互动） |
| **展望类** | 梦想描绘 / 未来展望 / 行动号召 | 收尾升华的燃料 |

**比赛向警告：煽情要有度。** 头马评分逻辑重内容与技巧，不重眼泪——有演讲者声泪俱下、过度煽情，反而掉分。

**素材管理工具**：灵感库（App，支持拍照转文字）、飞书文档、云盘材料包——工具不重要，**定期回顾**才重要。

## 5. 三层价值模型（价值点从哪里来）

源自《真需求》（产品经济学：功能价值 / 情绪价值 / 资产价值）向演讲的迁移：

| 层 | 定义 | 判据 |
|---|---|---|
| **逻辑价值** | 认知增量、心智增量 | 不讲大家都懂的道理——"要努力"没有增量 |
| **情绪价值** | 触动内心柔软，或激发昂扬斗志 | 听完心里动了 |
| **资产价值** | 人生经历可沉淀、可复用、可迭代，产生**复利效应** | 这段经历后来还被反复使用（写书、做产品、二次演讲） |

**判分逻辑**：头马比赛演讲必须有较高价值，否则分数一定低。一篇稿子**三层价值都放上去，价值维度必然是高分**。

**资产价值是三层里最少人提的一层，也是拉开差距的一层**：同一个素材，讲完就扔是消费，讲完沉淀成方法论、产品、复利资产才是投资。

> 与 `speech-writing-methodology.md` 的关系：那里是"好演讲 = 逻辑价值 + 情绪价值"两层，本文补上第三层**资产价值**。评估稿子时按三层过。

## 6. 价值点提炼三技巧：思辨 / 共鸣 / 非共识

| 技巧 | 定义 | 现场案例 |
|---|---|---|
| **深度思辨** | 本质洞察，把常识升级为方法论 | 小马哥"战胜中文演讲冠军"的故事：从共识版"要努力/亮剑精神"升级为**"挑战高手是最有性价比的进步模式"**——输了不丢脸，赢了自信心和能力都上来了，且可据此持续去找高手同场竞技 |
| **情绪共鸣** | 让观众听到自己"一直想说但没说出口的话" | 价值点直抵集体沉默的经验 |
| **非共识** | 与常人说法不一样 | "儿子大二要创业该不该放手"：共识版是"该放手就放手"（平淡）；非共识版是**"AI 时代，不冒险是最大的冒险"**——读完好大学找安稳工作这条路已经不存在了，必须持续探索 |

**操作顺序（挖不深时的强制动作）**：
1. 先写出素材的**"共识版"**价值——大家都会说的那句话
2. 强迫自己问一句：**"反过来讲成立吗？"**
3. 往**思辨**或**非共识**方向再推一层

> 只停在共识版 = 正确的废话 = 三重境界第三重缺失 = 比赛必掉分。

**两条提炼路径，正交、都要过**：

| 路径 | 方向 | 操作 | 出处 |
|---|---|---|---|
| **横向反转** | 从共识到非共识 | 写共识版 → 问"反过来讲成立吗？" | 本文 §6 |
| **纵向追问** | 从现象到本质 | **What（是什么）→ Why（为什么存在）→ So What（这揭示了什么）**，终极答案即演讲主题 | `inspiration-workshop.md` §3 |

> 只纵向不横向 = 有深度但不意外；只横向不纵向 = 有反差但没根基。

## 7. 核心张力三维度（选题坐标系）

所有张力逃不出三种人的关系，选故事先界定维度：

| 维度 | 典型冲突 | 示例（来自三个月项目案例） |
|---|---|---|
| **人与自我** | 自洽 / 欲望与道德 / 恐惧与勇气 / 理想与现实 / 选择困难 | 与内心的恐惧搏斗：这么难的项目怎么做出来，甚至恐惧到想逃避 |
| **人与他人** | 竞争对抗 / 利益冲突 / 价值观冲突 / 误解隔阂 | 善用他人资源：挖来高手、从客服部借调两个主管（只开口要组长，对方给主管——"关系到位"） |
| **人与世界** | 生存危机 / 资源匮乏 / 体制压迫 / 时间紧迫 | 科技重塑生活：凯文·凯利（KK）——人将永远处于"菜鸟阶段"，一门技术刚学会就又更新了 |

**维度的核心用法**：**同一个素材换维度讲，就是不同的演讲。**（《撞破南墙》案例：人与自我版讲恐惧与搏斗，人与他人版讲资源与人情。）素材枯竭时，先别找新素材，先换维度。

> 维度定义详见 `speech-writing-methodology.md` §二，此处补的是"换维度=换演讲"的用法。

## 8. 特征指纹：素材的结构化标签

每个素材背后可提取三层"指纹"，这是素材分类、检索、组合的依据：

1. **核心张力**：人与自我 / 他人 / 世界 × 具体冲突（§7 的细分项）
2. **行为机制**：故事中的行为是怎么产生的
   - 认知机制：认知过载 / 信息不对称 / 注意力分散 / 框架效应
   - 动机机制 / 能力机制 / 环境机制
3. **内心体验**
   - 情绪反应：快乐 / 愤怒 / 悲伤 / 恐惧 / 厌恶 / 惊讶
   - 自我感知：成就感 / 挫败感 / 掌控感 / 失控感
   - 人际连接：归属感等

**用途**：给每个素材打上指纹标签后，"素材匹配"变成可操作的事——**把张力点一致的素材自动归堆**。

例：都含"理想与现实 + 技能缺口 + 成就感"的几个故事 + 一句金句 + 一组数据，就是一篇演讲的天然素材组。

> 这是 AI 辅导时给素材打标签的**统一词表**。指纹一致 = 可以放在同一篇稿子里；指纹打架 = 硬凑会散。

## 9. 结构骨架库（五大结构 + 适用场景）

| 结构 | 骨架 | 适用场景 |
|---|---|---|
| **黄金圈** | Why → How → What | 目标类、动力类主题；Why 从生理学上最直击人心（Simon Sinek 白板演讲版值得观摩） |
| **PREP** | 观点先行 → 原因 → 案例 → 回扣观点 | 700 字短稿到中长稿通用的最常用结构。**先开诚布公说观点，最适合观点驱动型演讲**。（即兴用法见 `table-topics-toolbox.md`） |
| **时间轴 PPF** | 过去 → 现在 → 未来 | 磅礴大气的宏观叙事 |
| **SCQA** | 情景 → 冲突 → 问题 → 回答 | 路演、汇报场景 |
| **英雄之旅** | 起承转①转②合升 | 人人都爱听故事，讲自己的转变（**备稿首选**，见 `speech-writing-methodology.md` §四） |

**选型第一问**：这场听众要什么？——要观点给 PREP，要故事给英雄之旅，要气势给 PPF，要方案给 SCQA，要信念给黄金圈。

**选型第二问**：演讲者是什么水平？——**新手 / 5 分钟以内短稿用三幕结构**（建立世界 1′ → 遭遇挑战 3′ → 解决与转变 1′），粒度粗、好上手；**冲小区赛以上用英雄之旅六阶段**，会强制拆分认知转变与情绪转变。详见 `inspiration-workshop.md` §4。

## 10. 英雄之旅本土化：起承转转合升

传统是"起承转合"，本讲把**"转"拆成两个，并追加一个"升"**（六阶段定义见 `speech-writing-methodology.md` §四，此处补现场解构与细节技巧）：

| 环节 | 内容 | 《撞破南墙》对应 |
|---|---|---|
| **起** | 界定故事维度（人与自我 / 他人 / 世界） | 人与自我：接到不可能的任务，内心恐惧到想逃避 |
| **承** | 事件如何触发 + 挑战 + 困难 | 美国公司要 1~2 年上线，老板拍死 3 个月；下属杰夫说 P 语言没人用过、中美商业逻辑不同；赴美培训时差没倒、听不懂，四个人只能轮流每人听 1 小时（"薛定谔的猫"状态：一会清醒一会像做梦） |
| **转①：转认知** | 原来的认知被颠覆——"不可能"变成"我能干" | 撞玻璃顿悟：想跳楼没成，头上起大包，玻璃没裂缝——made in China！"我也是 made in China，中国人会制造奇迹"；再想起淝水之战 8 万胜 33 万，也是四倍奇迹 |
| **转②：转情绪** | 绝望 → 亢奋 | 从抑郁、失去理智（连轻轨都不让睡觉），到幡然悔悟后斗志昂扬、自信无畏（"功夫熊猫"状态） |
| **合** | 认知 + 情绪改变后，行动改变 → 结局 | 独创"三才剑法"（天才/地才/人才）：挖高手、番茄工作法提效、长板理论分工（擅长速度的写基础代码，一人主攻核心算法）；中途高手高烧住院两周、副手因母亲患癌休假，让测试员顶上、借调两个客服主管做测试；找老师要先进算法，8 小时算力变 15 分钟——**3 个月完成项目，拿到 8 个月奖金，合计 11 个月工资 ≈ 四倍报酬** |
| **升** | 反思升华，"上价值"：提炼普世核心价值，个人故事升华为共鸣人生哲理 | **"南墙不是阻碍，而是考验"**（甚至直接说：是机遇）——撞破的南墙是通往新生和蜕变的必经之路；再推一层：**废墟之上建新城，铸就新的长城**；首尾呼应：开头说要去挑战，结尾把墙撞破 |

### 讲故事四技巧（从案例中归纳，磨稿时逐条过）

- **具体细节制造可信度**：撞玻璃起大包、玻璃没裂缝、芝加哥轻轨震耳欲聋——**细节越具体，画面越真**
- **状态比喻**：薛定谔的猫（半梦半醒）→ 功夫熊猫（亢奋坚定），**用一个比喻把状态 A 到状态 B 讲活**
- **数字呼应**：淝水之战 8 万 vs 33 万 ≈ 四倍 ≈ 3 个月 vs 1 年——**历史数字与个人数字形成互文**
- **金句收尾 + 首尾呼应**：挑战开始 → 墙已撞破

## 11. 一材多用：同一素材的五种讲法

**一个素材至少能写三篇以上。** 以《撞破南墙》（三个月项目案例）为例：

| 结构 | 演绎 |
|---|---|
| **英雄之旅** | §10 完整版：起承转转合升全套 |
| **黄金圈** | Why：为什么要接不可能完成的项目 → How：转变心态 + 发明新工作方法 → What：3 个月完成，效率四倍 |
| **PREP** | 观点：南墙不是阻碍，是考验、是机遇 → 原因：绝境激发潜能、打破自身壁垒 → 案例：故事全讲 → 升华：以后要**主动**去寻找南墙、撞破南墙，这是勇气更是自我突破的必经之路 |
| **时间轴 PPF** | 过去：陷入绝望、决定反击、成功、结出经验 → 现在：写书（《极简时间管理》）、做出四倍效率软件、实现财务自由 → 未来：把四倍速方法论推广给大众，帮 3.3 亿人提高三倍效率 |
| **SCQA** | 情景：重要项目落地，时间只有别人的 1/4 → 冲突：难度超乎想象、时间很紧 → 问题：怎么办 → 回答：选择挑战，壮阔内心旅程，创造奇迹 |

**教学要点**：素材是矿石，结构是切工。备稿时**先想清楚这场听众要什么，再选结构**。

> **练法指令**：把一个讲过的素材换两个结构重写，是突破"素材枯竭"最快的练习。

## 12. 三重境界（最终自检清单）

1. **有故事**——生动，最好是自己的（自己的体验最强烈）
2. **有结构**——英雄之旅 / 黄金圈 / 时间轴 / PREP 任选
3. **有价值点**——非共识的洞察 + 深度的共鸣

三重逐级往上：**只有故事是流水账，有结构是合格的稿，有价值点才是能赢比赛的稿。**

（完整标尺见 `speech-writing-methodology.md` §六）

**配方版本——好演讲四要素**（比三重境界多一维"反复打磨"，见 `inspiration-workshop.md` §5）：
`真实经历（原料） × 清晰观点（骨架） × 情绪共鸣（灵魂） → 反复打磨（淬炼）`
> 前三重要素靠写，第四重要素只能靠练。

## 13. AI 辅助备稿链路（蛋导的辅导顺序）

讲者自研的灵感库 App 工作流，蛋导直接采纳为**备稿辅导链路**：

1. **录入素材**：文字输入或拍照（AI 自动 OCR 转文字，例如拍下好的一页 PPT）
2. **AI 自动提取**：内容形式归类（叙事类 / 数据类…）+ 特征指纹（核心张力点 / 行为机制 / 内心体验）+ 价值点挖掘（含非共识观点）
3. **人机纠错**：AI 提取不一定对——用户回复"不是这个情况"，AI 调整匹配逻辑后重提
4. **指纹匹配成组**：多个故事 + 金句 + 数据，按特征指纹自动匹配出最匹配的素材组合
5. **逻辑链条分析**：AI 给出这组素材如何串起来的逻辑链
6. **生成讲稿**：可选 2 分钟 / 5 分钟 / 7 分钟，中文或英文，生成后可继续修改

**对蛋导的硬约束**：
> 备稿辅导的顺序必须是 **"先喂素材 → 再提指纹 → 后选结构 → 最后成稿"**，而不是拿到题目直接生成。**素材指纹是中间的关键中介层。**

完整链路：**听众 → 素材 → 指纹 → 价值 → 结构 → 成稿 → 张力自检 → 三重境界验收**

> v4.0 补充：**"听众"前置为第 0 步**（详见 `audience-analysis.md` §1 画像五问）。同一批素材，讲给头马会员和讲给公司领导是两篇稿子——先定听众，再挖素材，否则价值提炼会跑偏。
> 结构选型除本文件 §8 的五结构选型表外，九骨架选型与逻辑组织见 `structure-and-logic.md` §1-§2。
