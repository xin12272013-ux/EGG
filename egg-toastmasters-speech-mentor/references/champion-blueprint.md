## 1. 前置定调（决定演讲上限，90% 的人翻车在这一步）

### 1.1 演讲目标四分类（先定目标，再写稿）

| 类型 | 目的 | 典型场景 |
|---|---|---|
| **信息型** | 科普、教学、分享知识 | Pathways 教学型项目、工作坊 |
| **激励型** | 唤醒听众、成长分享 | 比赛、开幕致辞 |
| **说服型** | 改变认知、促成行动 | 竞聘、路演、倡议 |
| **娱乐型** | 让人笑、让人轻松 | 幽默演讲、年会 |

**铁律**：一篇演讲只能有**一个**核心目的，**严禁混杂**。又想科普又想煽情 = 两个都没做到。

> **比赛演讲首选：激励型 + 认知颠覆。** 这是最容易拿高分的类型组合——激励型自带情绪曲线，认知颠覆自带"非共识"增量（对应 `material-and-tension.md` §6 的共识版→非共识版）。

### 1.2 天时地利人和（比赛专属的赛前判断）

| 维度 | 判断什么 | 该做的动作 |
|---|---|---|
| **天时** | 比赛听众一天听十几篇，**阈值极高** | 必须上悬念、冲突、金句、情绪。平淡不出错 = 隐形 = 不进第二轮 |
| **地利** | 大区是**大舞台**，观众离你远 | 音量、手势幅度、走位范围**整体上提一档**。在例会小会议室刚好的幅度，在大舞台会显得拘谨 |
| **人和** | 评委和多数观众**不认识你** | 内容必须贴**全场共同痛点**（失败、被否定、不敢开口、至亲、选择）。小众自我故事、俱乐部内部梗一律清零 |

> 与 `audience-analysis.md` 的分工：那份做**听众画像**（五问 + 六类听众 + EGG 四场景），这份做**赛前三项调整**。备赛时两份都要过。

### 1.3 五维黄金选题法（选题不过五维，别动笔）

| # | 维度 | 判据 |
|---|---|---|
| 1 | **亲身真实经历** | 真实的 = 最强的共情，编的故事在细节处必然露馅 |
| 2 | **自带天然冲突** | 困境、挣扎、反转、遗憾——至少占一样 |
| 3 | **打破大众固有认知** | 有观点差。听完让人"咦？原来还能这么想" |
| 4 | **普适所有人** | 职场、成长、心态、选择——不是只跟你行业相关 |
| 5 | **能提炼一句十字以内金句** | 十字以内才可能被记住，超过十二字就不是金句了 |

**四不选（绝对拿不了冠军）**：纯流水账 · 纯开心无困境 · 纯鸡汤无经历 · 小众专业内容。

> **用法**：先用 `material-and-tension.md` §1 人生曲线法挖出 5-8 个候选素材，再用五维筛——**能过 4 维以上才配写成比赛稿**。过不了 3 维的，拿去写例会稿，不要浪费在比赛上。

## 2. 比赛时间分配（7 分钟标准版）

| 区间 | 段落 | 任务 | 字数参考 |
|---|---|---|---|
| **0:00–1:00** | **凤头** | 钩子 + 坡道 + 抛出核心观点 | 150–200 字 |
| **1:00–4:00** | **猪肚** | 冲突故事 + 三层递进 + 情绪起伏 | 550–650 字 |
| **4:00–6:00** | **升华** | 从个人经历 → 大众普世启发 | 300–400 字 |
| **6:00–7:00** | **豹尾** | CallBack 闭环 + 金句定格 + 留白结束 | 150–200 字 |

**5 分钟比赛稿按比例压缩**：凤头 45″ / 猪肚 2′30″ / 升华 1′15″ / 豹尾 30″。

> **与 `polish-toolbox.md` 计时模板的分工**：那份按**段落**切（含 7:30 版本），这份按**功能**切。
> **最关键的一条差异**：**升华段独立占 2 分钟**。例会稿常把升华挤进结尾 30 秒——那是例会稿和比赛稿最大的结构级差距。稿子从例会搬去比赛，多半要**新写**这 2 分钟，不是改结尾。

## 3. 六大冠军通用结构（比赛选型速查）

| 结构 | 展开顺序 | 什么时候用它 |
|---|---|---|
| **① 英雄之旅**（比赛最高分结构） | 平凡日常 → 遭遇危机 → 跌入低谷 → 极致挣扎 → 关键转折 → 认知升华 → 回归赋能 | 有完整逆袭弧线的亲身经历 |
| **② SCQA 高阶叙事** | 场景铺垫 → 核心冲突 → 抛出疑问 → 给出答案（观点） | 价值观传递、情感共鸣 |
| **③ PREP 极简逻辑** | 观点 → 理由 → 故事案例 → 重申升华 | 观点型主题、稳妥不出错 |
| **④ 过去-现在-未来** | 旧认知困境 → 当下改变转折 → 未来行动启发 | 成长蜕变类首选（≈ `structure-and-logic.md` 骨架 8 时间轴） |
| **⑤ 问题-根源-对策-价值** | 大众痛点 → 底层原因 → 个人破局经历 → 全员启发 | 深度思辨型，评委偏爱 |
| **⑥ 单观点三故事递进** | 三个小故事层层叠加，全部服务同一个唯一金句 | 没有单个大故事，但有一堆小瞬间（≈ 冠军骨架"多 vignette 串珠"） |

> 完整十一骨架选型与逻辑序见 `structure-and-logic.md` §1-§2。**这张表是比赛的短名单**——不确定的时候，从①和⑤里挑。

### 3.1 冠军铁律：全篇只有一个核心观点

7 分钟只讲一件事、只传一个道理。**所有故事、对话、细节、情绪、结尾，全部为唯一金句服务**，无任何无关内容。

**验收动作**：把稿子的每一段问一遍——"这段是在为那句金句服务，还是因为写得好舍不得删？"后者全砍。

## 4. 故事工程（演讲的灵魂，决定感染力）

### 4.1 冠军故事万能公式

**欲望 → 阻碍 → 挣扎 → 关键选择 → 转折结果 → 认知成长**

三不判据：**无冲突 = 无感染力 · 无挣扎 = 无共鸣 · 无转折 = 无高分。**

### 4.2 故事三要素（区别普通会员的地方）

| 要素 | 说明 |
|---|---|
| **外部冲突** | 环境、他人、困境、现实压力 |
| **内部冲突**（**冠军核心**） | 自我怀疑、纠结、恐惧、不甘、两难选择 |
| **完整人物弧光** | 演讲者必须完成「**旧我 → 新我**」的认知蜕变 |

> **内心冲突 > 外部冲突。** 内心挣扎越深，听众共情越强。外部困难只是舞台，内心的两难才是戏。
> 与 `material-and-tension.md` §2 张力五来源的分工：那份讲"张力有哪五种来源"，这份讲"**冲突要分内外两层，且内层优先**"。

### 4.3 五感沉浸式描写法（画面感绝杀）

**彻底删除所有抽象形容词**：紧张、难过、开心、尴尬、迷茫、感动、后悔……
**全部替换为五感具象细节。**

| 感官 | 细节词库 |
|---|---|
| **视觉** | 汗水、颤抖的手、昏暗的灯光、攥皱的纸、不敢抬起的头 |
| **听觉** | 心跳声、突然的安静、嘈杂、回声、自己的呼吸声 |
| **触觉** | 手心冒汗、手脚冰凉、肩膀紧绷、腿发沉 |
| **嗅觉** | 压抑的空气、烟火味、雨后的潮湿 |
| **味觉** | 苦涩、发酸、口干得说不出话 |

> 判据：写完一段，把形容词全划掉，**剩下的细节能不能让人"看见"**？看不见就是没写够。
> 这是**去 AI 味最有效的一招**——AI 写出来的稿子，形容词密度天然偏高，细节密度天然偏低。

### 4.4 真实内心动态写法（高级走心必杀技）

不要只写"我很纠结"。要写：

> "我站在原地，进退两难。往前怕失败，退后怕遗憾。那一刻我不知道自己该坚持，还是该放弃。"

**把心理活动可视化，是冠军和普通人的最大区别。**

### 4.5 实景对话植入（让故事活起来）

**高级故事 = 30% 叙述 + 40% 对话 + 30% 内心戏。**

用真实台词替代概括叙述，区分人物的语气、态度、反差。

| 写法对比 | 效果 |
|---|---|
| ❌ 叙述："师父批评了我一顿" | 听众听到的是转述 |
| ✅ 对话：师父说："你这稿子是写给谁看的？"我说："写给评委。"他说："那完了。" | 听众在现场 |

> 这个 30/40/30 配比可以直接当**诊断标尺**：把稿子按字数统计一遍，对话占比低于 20% 的，故事一定是"讲"出来的，不是"演"出来的。

### 4.6 情节起伏节奏设计（杜绝平铺直叙）

一篇冠军演讲必须有完整六拍：

**平淡 → 压抑 → 低谷 → 反转 → 释然 → 升华**

有低才有高，有痛才有悟，有困境才有成长。

> 与 `material-and-tension.md` §2 的张力自检（≥2 次下压与反弹）互补：那份给**次数判据**，这份给**形状模板**。六拍走完，自然满足 2 次以上起伏。

## 5. 幽默（比赛密度标准）

### 5.1 四技法

| 技法 | 怎么做 | 安全度 |
|---|---|---|
| **三段式反转** | 铺垫常规逻辑 → 前两句顺着说 → **第三句意外反转** | 高 |
| **适度自嘲** | 自我调侃、接纳不完美 | 最高（最共情） |
| **极致夸张** | 放大生活小事制造喜剧反差 | 中 |
| **CallBack 梗复用** | 前期埋梗、后期回收 | 高（高级幽默闭环） |

### 5.2 比赛密度与原则

- **密度**：笑点均匀分布，每 30–60 秒一个，不要扎堆（同 `polish-toolbox.md` 幽默原则 1）
- **铁律**：幽默不喧宾夺主，**服务主题、不脱离观点**。搞笑是加分，价值是核心
- **禁区**：不碰情感高潮。走到走心的地方，幽默立刻收住

> 技法细节（五种类型、六条原则、续句补刀）见 `polish-toolbox.md` §工具3。**本表补的是"三段式反转"与"CallBack 梗复用"两型**——后者的高级之处在于笑点本身也成了闭环的一部分。

## 6. 闭环体系（冠军专属，普通选手几乎不用）

### 6.1 CallBack 首尾闭环（必做，大赛高分关键）

**开篇埋下**五类之一 → **结尾精准回收**，前后完全呼应：

| 埋点类型 | 例子 |
|---|---|
| **画面** | 开头"我坐在车里没上去" → 结尾"现在我下车了" |
| **问句** | 开头抛一个问题不答 → 结尾回答它 |
| **道具** | 一个实物贯穿全场 → 结尾让它改变意义 |
| **细节** | 一个动作、一个数字 → 结尾复现 |
| **金句** | 短句在开场/中段/结尾各出现一次，像副歌 |

**效果**：结构极致完整、记忆点极强、评委观感高级。

> 与 `structure-and-logic.md` 骨架 9（回环式）的分工：回环式是**一种骨架**，CallBack 是**可与任意骨架叠加的手法**。比赛稿无脑加。

### 6.2 双记忆锚设计（听完一辈子记得你）

| 锚 | 是什么 | 要求 |
|---|---|---|
| **视觉锚** | 专属道具、标志性动作、画面意象 | 全场可见，出现 ≥2 次 |
| **文字锚** | 10 字以内核心金句 | 全篇反复**轻**呼应（不是重复三遍，是换个说法再点一次） |

> 判据：观众散场后能复述出你的金句 → 文字锚立住了；能描述出你的一个画面/动作 → 视觉锚立住了。两个都没有，讲完就忘。

## 7. 声音（比赛日的分配与匹配标准）

### 7.1 四大控制维度

| 维度 | 比赛标准 |
|---|---|
| **语速快慢** | 铺垫快（220-260）→ 低谷慢（120-160）→ 转折停顿 → 升华极慢（60-100） |
| **音量高低** | 困境压低（近乎耳语）→ 觉醒拉高 → 金句重音放大 |
| **抑扬顿挫** | 拒绝念经平调，句句有起伏 |
| **精准停顿** | 见下表 |

### 7.2 停顿三档（最强武器）

| 位置 | 停顿 |
|---|---|
| 观点抛出后 | **1 秒** |
| 情绪高点 | **1–2 秒** |
| 金句之后 | **2 秒**（全场最震撼时刻） |

> 与 `delivery-craft.md` §2.3 的分工：那份给**停顿四型**（标点/强调/重停顿/等笑声/沉默），这份给**比赛日三档秒数**。冲突时以 `delivery-craft.md` 为准，它更细。

### 7.3 情绪声音匹配铁律

| 内容 | 声音 |
|---|---|
| 悲伤 | 低沉、放缓 |
| 挣扎 | 颤抖、轻微紧绷 |
| 觉醒 | 坚定、清亮、有力 |

**文字、情绪、声音 100% 统一**，不出现反差割裂。（讲着最痛的事却用平稳愉快的语调，是最常见的隐性失分。）

### 7.4 口头禅清零标准

全程无：**嗯、啊、然后、就是、其实、那个**。
**用停顿留白替代所有口头禅**——想说"然后"的时候，闭嘴，沉默 1 秒。

## 8. 舞台（比赛日的气场标准）

| 项 | 标准 |
|---|---|
| **站姿（外松内紧）** | 双脚与肩同宽、重心居中、上身挺拔、肩膀放松；**全程不乱踱步、不左右摇摆** |
| **手势** | ① 舒展、打开手掌（包容真诚）② 不指点、不僵握拳 ③ 情绪弱→小手势，情绪强→大开大合 ④ **手势和台词完全同步**，不脱节不多余 |
| **眼神三分法** | 左—中—右全场覆盖；不盯地板、不盯天花板、**不盯单一观众** |
| **眼神情绪匹配** | 讲低谷→收敛柔和下沉；讲觉醒→坚定平视明亮；**金句时刻→定格环视全场，停顿对视** |
| **面部表情** | 难过沉静 / 释然柔和 / 坚定明亮 / 自嘲松弛。**7 分钟表情丰富自然，无面瘫** |

> 训练方法（手势三区、分区眼神、三点走位、21 天训练表）见 `delivery-craft.md` §3-§4、§8。本表只给比赛日的**达标线**。

## 9. 结尾升华体系（豹尾定胜负，决定冠亚季军）

### 9.1 三层升华（缺一层就上不去）

1. **复盘个人蜕变**：旧我破碎、新我成长
2. **链接全场听众**：映射**所有人**的人生困境（从"我"到"你"）
3. **给出普世人生哲理 + 温柔赋能 + 行动号召**

**结尾金句必须**：简短、锋利、好记、有力量。

### 9.2 最后 3 秒

**定格站姿 + 坚定眼神 + 静默留白，再鞠躬收尾。**

说完最后一句先停 1 秒再动（同 `delivery-craft.md` §2.1）。**急着走 = 把刚建立的气场自己打散。**

> 与 `structure-and-logic.md` §5.2 的分工：那份给结尾的**任务与三个禁止**（禁止总结、禁止新信息、禁止"让我们一起"），这份给**三层结构与最后 3 秒的定格动作**。

## 10. 打磨流程（小白 → 冠军的必经步骤）

### 10.1 写稿四步闭环

1. **搭骨架**：先结构、再观点，**不写故事**
2. **填冲突**：强化内心挣扎、情节起伏
3. **加细节**：五感、对话、内心戏全覆盖
4. **全打磨**：删废话、统一金句、闭环 CallBack、调整节奏

> 与 `material-and-tension.md` §3 三步曲（记录→提炼→结构加工）的分工：三步曲解决"**内容从哪来**"，四步闭环解决"**成品怎么造**"。四步里的第 1 步就是三步曲的产物。

### 10.2 三遍迭代法（每次改稿只走一遍，不要一次改完）

| 遍 | 只做什么 |
|---|---|
| **第一遍** | **通顺完整**（别管好坏，先有全稿） |
| **第二遍** | **删所有无关内容，聚焦唯一观点**（砍掉写得最好但离题的段落） |
| **第三遍** | **调情绪、调节奏、埋钩子、做闭环、升价值** |

> **顺序不能跳。** 第一遍就调情绪 = 给一段注定要被删掉的文字抛光，是新手最浪费时间的动作。

### 10.3 视频复盘自查六项

每练一遍录视频，逐项自查：
- [ ] 语速是否平调
- [ ] 有无口头禅
- [ ] 肢体是否僵硬
- [ ] 情绪是否匹配
- [ ] 有无冷场节点
- [ ] 结尾是否有力

> 怎么看录像（三遍法：只听声音 / 只看画面 / 正常看）见 `evaluation-playbook.md` §5.1。本表是**查什么**。

## 11. 赛场心态与临场救场

### 11.1 顶级心态三条

1. **演讲是给予价值，不是表演讨好**
2. **接受不完美**：轻微口误、停顿，无需道歉、无需慌张，直接顺延
3. **焦点放在内容传递，不放在自我形象**

### 11.2 临场失误三条救场法则

| 状况 | 怎么做 | 绝不做 |
|---|---|---|
| **忘词** | 停顿 + 环视 + 慢语速自然衔接 | 站在那里"嗯……"超过 3 秒 |
| **口误** | **直接忽略，不解释、不纠错** | "哎呀我说错了"——一说错，全场注意力全到错上 |
| **冷场** | 抛出短句金句 + 轻微停顿控场 | 加快语速硬冲过去 |

> 与 `delivery-craft.md` §4 意外处理表的分工：那份覆盖设备、超时、观众提问等**全部意外类型**，这份是**比赛现场最高频的三条**，动作更具体。

## 12. 大区冠军验收清单（定稿前逐条打勾，满分达标）

**用法**：模式 B 评估完、模式 D 磨完，拿这张表给稿子做最后一道体检。**任何一项不过，都不要定稿。**

### 结构
- [ ] 单一核心观点
- [ ] 结构完整
- [ ] 首尾闭环
- [ ] 时间精准（实测误差 ≤15 秒，且不超时）

### 内容
- [ ] 真实亲身经历
- [ ] 强冲突（外部 + 内部）
- [ ] 完整人物弧光（旧我 → 新我）

### 描写
- [ ] 五感细节饱满
- [ ] 无抽象形容词
- [ ] 内心戏充足
- [ ] 对话生动（对话占比 ≈40%）

### 开篇
- [ ] 10 秒锁住观众
- [ ] 无废话坡道（不自我介绍、不寒暄、不铺垫）

### 节奏
- [ ] 起伏明显（平淡→压抑→低谷→反转→释然→升华）
- [ ] 快慢停顿精准
- [ ] 情绪层层递进

### 舞台
- [ ] 声音贴合情绪
- [ ] 肢体自然（站姿稳、手势同步）
- [ ] 眼神全覆盖
- [ ] 气场稳定

### 结尾
- [ ] 普世升华
- [ ] 金句记忆锚
- [ ] 赋能全场
- [ ] 余味悠长（最后 3 秒定格留白）

### 加分项
- [ ] 幽默自然
- [ ] CallBack 闭环
- [ ] 道具记忆锚
- [ ] 无口头禅

**统计口径**：正文 8 项，全过 = 大区级达标线；加分项过 3 项以上 = 有竞争力；加分项全过 = 冲冠军。

## 附：手册原文的一句话立场

> 普通演讲：有内容、有结构、讲得通顺。
> 冠军演讲：有钩子、有画面、有冲突、有情绪、有节奏、有记忆锚、有普世价值、全程观众不掉线、听完能记住一辈子。
> **冠军演讲不是天赋，是标准化、模块化、可复制的工程。**
