# EGG 小红书爆款内容系列工作流

## 0.5 ⚠️ 小红书引流红线（必读，否则直接限流 0 浏览）

小红书对**站外引流**零容忍，公开笔记/图里出现以下词会被判定营销号、不进推荐池：
群、微信群、进群、拉群、私信、加我、微信、vx、V信、二维码、扫码、清单、发你、扣XX发、主页留微。

**安全漏斗（已验证）**：
- 公开笔记**只抛开放式提问**驱动评论（"你第一次上台最怕什么？"），绝不送资料、不写群。
- 用户评论后，你用**小红书私信**回一张清单长图（图中也别带群/微信/二维码字样）。
- 长期沉淀引导加**小红书群（站内群）**，比微信安全。
- 私信里同样别发微信号/二维码，发图即可；要加微信让用户主动说，你再回。
- 老号若因引流词 0 浏览：**编辑已发帖替换正文**（别删帖，删帖伤权重），1–2 天流量回升。
- 新号先养号：每天刷同赛道 20 分钟、点赞收藏评论 10–20 条打标签再发。

## 0.6 📍 地域定向（本地流量，线下俱乐部的命根子）

**核心判断**：EGG 是**线下**俱乐部，要的是"周日上午能走进徐汇那间屋子的人"。
100 个上海本地浏览 >> 10000 个外地浏览。**主动牺牲全国泛流量，换本地精准流量，是划算的。**

### 为什么流量全是外地的

笔记里没有任何地域信号 → 小红书按兴趣标签推给全国。
只把"徐汇云锦路181号"当俱乐部地址写一次，权重极低，几乎不触发同城池。

### 地域信号权重（从强到弱）

| 权重 | 手段 | 做法 |
|---|---|---|
| ★★★★★ | **发布时带 POI 定位** | 发布页「添加位置」选**热门 POI**（徐汇滨江 / 龙华寺 / 云锦路）。热门 POI 自带流量池，比冷门机构名强很多 |
| ★★★★ | **标题含城市/区名** | "上海""徐汇"入标题，直接被地域识别抓取 |
| ★★★ | **标签含地域词** | 见下方标签库，地域标签是同城池的主要入口 |
| ★★ | **正文自然出现地名** | 徐汇滨江、龙华、黄浦江边、地铁 11 号线——具体地名越密，地域信号越强 |

### 双轨制（别把所有篇目都地域化）

| 类型 | 占比 | 标题带地域？ | 作用 |
|---|---|---|---|
| **地域篇** | 每周 2–3 篇 | ✅ 带"上海/徐汇" | 拉本地人到场，进同城池 |
| **全国篇** | 每周 2–3 篇 | ❌ 不带 | 干货/单招，养号权重与粉丝基数 |

地域篇牺牲全国流量换精准，全国篇反过来给账号涨权重——**两条腿走路，不要全押一头**。

### 标签配比（8 个）

- **地域篇**：3 地域 + 3 人群 + 2 大词
- **全国篇**：0 地域 + 5 人群 + 3 大词

**地域词库**：`#上海` `#上海周末去哪儿` `#上海线下活动` `#上海社交` `#上海职场` `#徐汇` `#上海演讲` `#上海读书会`
**人群词库**：`#社恐` `#不敢说话` `#表达能力` `#演讲` `#领导力` `#职场沟通` `#自我介绍`
**大词库**：`#个人成长` `#自我提升`

⚠️ **反面教材**：`#向上管理` `#团队协作` `#领导力` `#个人成长` `#自我提升` 这类万金油大词
竞争激烈、人群不精准，单独用会引来大量非目标人群（已被 9/2 官员篇验证：数据低于均值）。

### 地域篇正文写法

地名要**自然长在场景里**，不要贴广告：
- ❌ "我们俱乐部在上海徐汇，欢迎上海的朋友来"
- ✅ "散场我从云锦路走到滨江，江风一吹才反应过来——刚才那三句又白说了"

封面右上角的 tag 位也换成地域信息（如「上海徐汇 · 周日 9:30」），图片地域信号同样有效。

## 1. 内容系列架构（错峰原则）

不要连发同构干货，按「角度轮换」排：
- 干货总览篇（收藏向，如"3招翻盘"）
- 情感故事篇（评论向，如"师父一句话治好了社恐"）
- 单招拆分篇（把总览里的每招扩成单篇，收藏向）
- 反向误区篇（避坑向，回扣干货）
- 成长背书篇（用真实经历做信任，如"7个官员大满贯"）

每篇统一软植入：金句 + 标语 + 例会信息。
⚠️ 结尾**用开放式提问驱动评论**，不要写"评论扣XX发清单/进群"等站外引流词（见 0.5 红线）。

## 1.5 🔍 低流量诊断清单（数据差时按序自查）

别急着改封面，按**权重从高到低**逐条排查：

1. **引流红线**（§0.5）→ 0 浏览的 99% 是它。有触发词就编辑改稿，**不要删帖**。
2. **地域定向**（§0.6）→ 有浏览量但**人群不是上海的**：缺 POI、缺地域标签、正文没地名。
3. **标题是不是"我"视角** → 见下方三大坑。
4. **术语堆砌** → 见下方三大坑。
5. **标签配比** → 万金油大词过多，人群被稀释。
6. **封面/开头钩子** → 收藏率 <8% 优化封面；评论率 <15% 优化开头。
7. **角度疲劳** → 连续 3 篇以上同构（都是"我学到了什么"），按 §1 错峰轮换。

### 三大坑（9/2《当了7个官，我的嘴才值钱》实测踩中，数据低于均值）

| 坑 | 表现 | 为什么扑 | 改法 |
|---|---|---|---|
| **1. 标题用"我"背书** | "我当了7个官""我靠这3招" | 这是**作者的战绩，不是用户的痛点**。算法判定"对目标人群预期价值低"，初始流量给不足 | 标题写**用户处境**："每次自我介绍都后悔"（不说我，说他） |
| **2. 头马术语堆砌** | 连续 7 个职务名：教育副主席、公关副主席、接待官… | 圈外人看不懂，被判"垂直圈层内容"减少推荐；且读者要的是解决自己问题，不是组织架构 | 职务名**全删**，改写成场景："被扔进七种不同的场合，逼着开口" |
| **3. 万金油标签** | #向上管理 #团队协作 #领导力 #个人成长 #自我提升 | 竞争大 + 人群杂，引来一堆非目标用户，互动率低又反过来压推荐 | 换成人群真实搜索词：#社恐 #不敢说话 #表达能力 |

**一句话原则**：把"我有多厉害"翻译成"你能拿走什么"。

## 2. 执行步骤（建议顺序）

1. 写笔记 md（标题 ≤18 字，含反差/利益点；正文用"场景钩子→人设→干货→EGG植入→CTA"五段）
2. 生成封面主视觉：`ImageGen` 出竖版 3:4 分裂屏（冷调左 / 暖光右 + 同一人反差），no text
3. 合成封面 JPG：用下方 PIL 模板把中文标题叠到主视觉上（深底+粉标签+金高亮+EGG底栏）
4. 裂变：把总览每招各做一张分镜封面（第1/2/3招），形成系列
5. 引流承接：写 `EGG入会清单.md` → 压成 `长图.jpg` + `朋友圈9-16.jpg` → 写 `私信自动回复话术.md`
6. 周更闭环：`EGG周日例会复盘模板.md` + `.jpg`（每周日 12:30 前发）
7. 发布总控：`EGG发布排期表.md`（标注每篇封面文件/类型/时间/目标/评论钩子/引流承接）
8. 资产盘点：`EGG内容资产总览表.md`（按文案/封面/长图/可视化/引流承接/早期版本/待办 7 维度）

## 3. 封面合成 PIL 模板（复用，改标题/颜色即可）

```python
import pathlib
from PIL import Image, ImageDraw, ImageFont
WS = pathlib.Path(r"F:/workbuddy/2026-08-25-21-52-10")  # 改成实际工作区
FB = r"C:/Windows/Fonts/msyhbd.ttc"   # 加粗
FR = r"C:/Windows/Fonts/msyh.ttc"     # 常规
PINK=(255,27,109); GOLD=(255,213,74); WHITE=(255,255,255); LIGHT=(232,236,245)
def F(p,s,i=0): return ImageFont.truetype(p,s,index=i)
def tw(d,t,ft): return d.textlength(t,font=ft)
def grad(d,x0,y0,x1,y1,a0,a1):
    h=y1-y0
    for i in range(h):
        a=int(a0+(a1-a0)*i/max(h-1,1)); d.line([(x0,y0+i),(x1,y0+i)],fill=(0,0,0,a))
def rbg(d,xy,text,fnt,pad,radius,fill,fg):
    x0,y0=xy; w=tw(d,text,fnt); x1=x0+w+pad*2; y1=y0+fnt.size+pad*2
    d.rounded_rectangle([x0,y0,x1,y1],radius=radius,fill=fill); d.text((x0+pad,y0+pad),text,font=fnt,fill=fg)
def render(src,out,kicker,title,sub,tag,egg,esub):
    im=Image.open(src).convert("RGBA"); W,H=im.size
    layer=Image.new("RGBA",(W,H),(0,0,0,0)); d=ImageDraw.Draw(layer)
    grad(d,0,0,W,int(H*0.30),200,20); grad(d,0,H-int(H*0.16),W,H,20,235)
    L=int(W*0.06)
    kb=F(FB,int(H*0.026)); rbg(d,(L,int(H*0.05)),kicker,kb,pad=int(W*0.014),radius=int(W*0.012),fill=(PINK[0],PINK[1],PINK[2],255),fg=WHITE)
    tf=F(FB,int(H*0.062)); ty=int(H*0.105); lh=int(tf.size*1.2)
    for line in title:                       # title: [[("段1",色),("段2",色)],...]
        cx=L
        for seg,col in line:
            d.text((cx,ty),seg,font=tf,fill=col); cx+=tw(d,seg,tf)
        ty+=lh
    sf=F(FR,int(H*0.03)); d.text((L,ty+int(H*0.01)),sub,font=sf,fill=LIGHT)
    tg=F(FB,int(H*0.022)); twt=tw(d,tag,tg); tx=W-L-twt-int(W*0.028)
    d.rounded_rectangle([tx,int(H*0.05),tx+twt+int(W*0.028),int(H*0.05)+tg.size+int(H*0.018)],radius=int(W*0.02),fill=(0,0,0,170))
    d.text((tx+int(W*0.014),int(H*0.05)+int(H*0.009)),tag,font=tg,fill=WHITE)
    eb=F(FB,int(H*0.032)); es=F(FB,int(H*0.024)); by=H-int(H*0.16)+int(H*0.04)
    d.text((L,by),egg,font=eb,fill=WHITE); d.text((L,by+eb.size+int(H*0.008)),esub,font=es,fill=GOLD)
    Image.alpha_composite(im,layer).convert("RGB").save(out,"JPEG",quality=92)
# 调用示例：
render(WS/"generated-images"/"主视觉.png", WS/"EGG封面_主图.jpg",
   "快乐哥 · 34年程序员",
   [[("嘴笨社恐，",WHITE),("我靠这",WHITE),("3招",GOLD),("翻盘了",WHITE)]],
   "在 EGG 头马，把话说好", "社恐逆袭 · 演讲干货",
   "EGG「诞」头马演讲俱乐部", "让你开口，诞生无限")
```

## 4. 长图/可视化生成要点

- 长图用纯 PIL 画深底渐变卡片，竖排 block，底部 CTA；尺寸 750×N，导出 JPEG quality=92
- Pathways 六卡用 2 列网格，每条：序号+英文名+中文(金)+适合谁，6 色区分
- 双 DTM 用竖向时间轴节点（圆点+卡片），6 站写真实成长路径
- 9:16 首屏版：把内容压进 1334 高内，不裁切卡片，适配朋友圈/私信
