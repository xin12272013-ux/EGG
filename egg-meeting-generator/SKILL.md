# EGG头马会议文件生成器

从会议角色接龙文本中提取信息，生成：
1. Excel Agenda (`EGG{号}次会议Agenda.xlsx`) — 正面/背面/议程反面/投票 4个sheet
2. PPT背景板 (`EGG - {号}次会议背景板.pptx`) — 幻灯片（261次时为35页，含4备稿+4个评）

## 261次实战经验（重要，覆盖早期文档）

1. **模板结构以实际dump为准**：258模板PPT实际33页（非文档写的30页）。生成前先dump全部slide文本建立1-based页号→内容映射，再换算0-based索引（易错位：S[13]是第14页）。
2. **258模板PPT页序**（1-based）：1封面(会议经理) 2接待官 3主席辞 4头马介绍 5架构 6EGG介绍(时间/地址) 7主持人 8总评团队(多行单段落) 9大咖分享 10提问官 11仪式页 12来宾介绍 13茶歇 14即兴主持 15-17备稿1-3 18即兴评估 19-21个评1-3 22哼哈报告 23语法报告 24时间报告 25总评报告 26投票 27入会规则 28-30 Pathways介绍 31颁奖 32感谢 33下期预告。（261次删仪式页后为34页）
3. **\x0b换行符陷阱（关键修复）**：多行文本框（如总评团队页）是一个段落内用`<a:br/>`分隔，para.text读出含`\x0b`。直接写入run.text会产生`_x000B_`字面量（PowerPoint显示乱码）。必须按`\x0b`分段重建`a:r`+`a:br`元素（保留首个run的rPr格式，插入到endParaRPr之前）。参考generate_261.py的set_para_text()。生成后用zipfile检查所有slide XML无`_x000B_`字面量。
4. **用户迭代式修订流程**：先按接龙生成v1，用户随后口头逐步修订（换人、删环节、调顺序、加环节）。**务必把全部修订写进生成脚本再整体重跑**（脚本从258模板幂等重建），不要在输出文件上打补丁——否则下次重跑会丢失修订。
5. **Excel议程行可扩展**：模板议程区7-34行，261次最终用到7-36行（30项）。超出时手动把备注区（35行起：官员团队/备稿目标/演讲目标）整体下移N行：**值、样式(_style)、行高三者都要下移**（openpyxl的insert_rows不移动合并单元格且样式易错位，用手动搬运更稳），新议程行复制行34表格样式并入，打印区域同步扩展（如B1:J42）。
6. **样式错位坑**：下移备注区时若只移值不移样式，"1.备稿目标"等标签会用错字体/底色。搬运后逐格核对C36/C38/C39/C40的font和fill一致性。
7. **备稿目标条数=备稿数**：4个备稿需4条备稿目标（原模板只有3条且第3条误标"演讲目标"）。261次最终备注区在37-42行，备稿目标1-4为C38-C41。
8. **新增幻灯片**：duplicate_slide_xml()复制后在末尾，需操作`prs.slides._sldIdLst`移动到正确位置（move_after函数）。
9. **待定替换需限定单页**：`('待定','XXX')`全局替换会误伤下期预告等页，必须按页索引替换。
10. **PPT页与Excel顺序天然对齐**：模板PPT第2页接待官、第3页主席辞在前，第27页入会规则、第31页颁奖在后——Excel议程调整顺序（如主席致辞提前、入会规则移到投票后）时PPT通常无需改动，先dump确认再决定。
11. **介绍环节顺序可自由调整**：261次最终顺序为 接待官→主席致辞→主持人开场→总评官→时间官→语法官→哼哈官→提问官。用户要求调换时只改Excel agenda列表+时间公式重写，PPT总评团队在第8页整体展示、无需单页介绍页。

## 262次实战经验（最重要，先看这一节）

1. **增量修订模式（262起的默认流程）**：快乐哥现在会先把上一版文件改名成新会议号（如 261→262）并发出来，文件里已经填好了会议号/日期/主题/大部分角色，接龙只补最后确认的人名。**不要从258/261模板整体重建**，应在原文件上做最小化 patch，且patch脚本要幂等可重跑（用`find_slide(prs, 标题)`按页标题定位，不写死索引）。
2. **孤儿 slide 部件坑（关键，必须先处理）**：262背景板里藏了3个261遗留的孤儿页——`ppt/slides/slide17.xml`(备稿演讲4 程雪@EGG)、`slide21.xml`(备稿个评3 橄榄树)、`slide22.xml`(备稿个评4 水泽枂)。它们**在 `ppt/_rels/presentation.xml.rels` 里挂链但不在 `ppt/presentation.xml` 的 `sldIdLst` 里**。python-pptx 会把它们一起序列化，保存时与正常页的 partname 撞车（zipfile 报 `Duplicate name`），结果孤儿页被插进正式页序——表现为"做完修改后PPT里冒出备稿演讲4/备稿个评4"。
   **检测**：读 `ppt/presentation.xml` 的 `<p:sldId r:id>` → 经 rels 映射出被引用页，与 zip 里全部 `ppt/slides/slideN.xml` 求差集。
   **修复**：在 zip 层先重建一份干净 pptx——删掉孤儿 `slideN.xml` 与其 `_rels/slideN.xml.rels`、删 `[Content_Types].xml` 里对应 Override、删 `presentation.xml.rels` 里对应 Relationship，再交给 python-pptx 编辑。参考 `scripts/patch_262.py` 的 `orphan_slide_parts()` + zip 重建段。
   **校验**：保存后再跑一次 `orphan_slide_parts()` 应为"无"，并检查 `presentation.xml` 里所有 rId 在 rels 中存在、各 slide rels 目标不悬空。
3. **接龙没有的环节要同步删页**：262接龙无提问官（Excel议程也没有该行），于是删掉PPT"提问官提问"页，并把第8页总评团队里的"提问官: 待定"一并去掉。原则：**PPT页必须与Excel议程一一对应**。
4. **删页用 drop_rel + 移除 sldId 元素**（`prs.part.drop_rel(el.get(qn('r:id')))` 后 `lst.remove(el)`），不要只删 shape。
5. **给页面加副标题**：EGG十分钟页需要显示分享主题时，复制"大咖分享"页副标题 shape 的 XML（`cp.deepcopy`），改 `a:t` 文本后 `name_ph._element.addnext(new_sub)` 插入；**同时把姓名占位符的 top/left 设为大咖分享页姓名的 top/left**（原 4.59in → 5.36in），否则姓名和副标题重叠。
6. **262次最终页序（30页）**：1封面 2接待官 3主席辞 4头马介绍 5架构 6EGG介绍 7主持人 8总评团队 9大咖分享 10来宾介绍+合照 11茶歇 12即兴主持 13备稿1 14备稿2 15EGG十分钟 16即兴评估 17个评1 18个评2 19哼哈报告 20语法报告 21时间报告 22总评报告 23投票 24入会规则 25-26 Pathways介绍 27新会员入会规则 28颁奖与致谢 29感谢 30下期预告。
7. **Excel openpyxl 往返安全**：EGG的Agenda.xlsx 含 5 张图片和 drawing1/drawing2，实测 openpyxl `load_workbook` → `save` 往返**不丢失**图片与drawing（仅丢 zip 目录项）。sharedStrings 会被内联，文件反而变小（214KB→198KB），属正常。

## 接龙解析规则

从用户贴出的接龙文本提取：

| 字段 | 提取方式 |
|------|---------|
| 会议号 | 标题中"第XX次" |
| 日期 | "X月X日周X"，转换为 `2026年X月X日` |
| 时间 | "上午/下午 X:XX - X:XX"，Excel起始时间取开始时间的 `time(hour, minute)` |
| 主题 | "主题：《XXX》" |
| 地点 | 地址行 |
| 费用 | 费用行，默认"所有来宾和角色全免费" |

**角色状态判断**：
- `[烟花]` → 未确定，Excel填"待定"，PPT填"待定"或"待定@EGG"
- `[玫瑰]` → 会员可认领，暂填"待定"
- 已有姓名 → 直接使用，格式 `姓名@俱乐部` 或 `姓名`

**PPT幻灯片新增判断**：
- 有备稿3 → 保留 Slide 28（备稿演讲3）
- 无备稿3 → 删除 Slide 28
- 有备稿个评3 → 保留 Slide 29（备稿个评3）
- 无备稿个评3 → 删除 Slide 29
- 有新会员入会仪式/生日会 → 保留 Slide 30
- 无相关活动 → 删除 Slide 30
- 有EGG十分钟 → 需要新增幻灯片

### 文本替换陷阱（重要）

1. **逐run替换**：PPT文字分散在多个 `<a:r>` 元素中，必须遍历 `para.runs` 逐项替换
2. **vertical tab**：模板中换行符可能是 `\x0B`（`_x000B_`），不是 `\n`
3. **重复替换**：同一人名出现在多页时注意上下文区分（如"快乐哥"在Slide 3和Slide 25都有）
4. **全局替换顺序**：先做全局替换（会议号、时间、地址），再做单页角色替换
5. **全局替换副作用**：`('快乐哥@EGG', '待定')` 这种替换只应在特定幻灯片上做，不能全局

### 额外幻灯片处理

258模板已有 Slide 28-30（备稿3、备稿个评3、入会仪式&生日会）。
若本次会议不需要某项，删除对应幻灯片；若需要新类型（如EGG十分钟），用 `duplicate_slide_xml()` 复制同类幻灯片模板。
