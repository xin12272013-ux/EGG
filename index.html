安装步骤

  1. 打开 WorkBuddy，点击左侧栏的 插件 图标，进入插件管理页面。
  2. 点击页面上的 ＋ 按钮（添加插件市场）。
  3. 输入本市场包的下载地址：
    https://（本页域名）/egg-toastmasters-marketplace-v1.0.0.zip
    确认后，市场列表中会出现 4 个 EGG 插件。
  4. 逐个点击插件的 安装 按钮，全部装完后 重启 WorkBuddy 生效。

egg-speech-mentor		 八维能力 + 四模式（从零生成 / 比赛级评估定级 / 反馈改稿 / 六维磨稿），含大区冠军工程蓝图。

依赖：pip install Pillow；另需安装通用技能 toastmasters-poster-prompt（复用其底层脚本）

egg-xhs-content-series		 选题 → 文案 → 封面图 → 长图 → 发布排期 → 引流承接一站式。

安装失败排查

现象原因与处理
添加市场提示找不到清单 填的必须是 zip 的直接下载链接（以 .zip 结尾），不能是网页地址或跳转页。
市场添加成功但列表为空 确认下载完整（比对 SHA256），zip 根目录应直接包含 .codebuddy-plugin/marketplace.json，而不是多套一层文件夹。
插件装了但技能不生效 重启 WorkBuddy；确认技能目录下 SKILL.md 存在，且其顶部 name 与技能目录名一致。
海报生成器提示缺脚本 需另装通用技能 toastmasters-poster-prompt，本技能复用它的叠字与合成脚本。
会议文件生成器报 ModuleNotFound 缺 python-pptx / openpyxl，执行 pip install python-pptx openpyxl。
评估/改稿导不出 PDF 未检测到 Chrome 或 Edge，安装任一浏览器后重试。
下载中断或文件损坏 重新下载，比对 SHA256 是否与本页一致。
